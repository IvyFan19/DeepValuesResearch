# Deep Value Research

An open-source research library for deep value investing, fundamental analysis, and contrarian market thinking.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
![Snapshot Date](https://img.shields.io/badge/Snapshot-February%2016%2C%202026-blue)

## Overview

This repository is a content-first knowledge base. It combines company-level deep dives, macro and market memos, investor philosophy research, and educational value investing frameworks.

**Disclaimer**: Content is for educational and informational purposes only and is not investment advice.

## How to Use This Repository

- Start with `Business Research/` for company-specific investment theses and financial deep dives.
- Use `Market Research/` to add macro context before forming a position.
- Read `Guru Research/` for framework calibration and decision-quality improvements.
- Use `Value Investing Principles/` as a method reference when reviewing assumptions and valuation inputs.
- Use `Warren Buffett Archive/` for historical primary-source context.
