# 前沿 AI 模型公司的鉅額算力承諾與對手方風險：雲端巨頭在資本清算瀑布中的隱性期權與價值捕獲分析

> **【核心問題解答】** 本文深入剖析前沿 AI 模型公司（如 Anthropic 與 OpenAI）在承擔數千億美元鉅額算力承諾下的財務結構脆弱性，以及此結構如何引發跨供應鏈的連鎖對手方風險（Counterparty Risk）。分析顯示：若前沿模型公司因資本消耗過快或融資受阻而進入美國破產法第 11 章（Chapter 11）重組，最大的長期受益者並非直接進行全盤收購的單一買家，而是同時握有雲端分發管道、客製化晶片（如 TPU、Trainium）以及資本防禦期權的雲端巨頭（Hyperscalers，包含 Google、Amazon 與 Microsoft），以及市場中剩餘的模型份額佔有者（如 Google Gemini）。對長期價值投資人而言，理解此機制能幫助我們看清 AI 產業鏈中真正的「價值捕獲層」（Value Capture Layer），在資本分配與破產清算瀑布中辨識具備安全邊際（Margin of Safety）與不對稱勝率（Asymmetric Risk/Reward）的優質企業。

## 1. AI 產業的大局觀：鉅額算力承諾與連鎖對手方風險 (Counterparty Risk)

在當前人工智慧產業的急速擴張期，前沿模型公司（Frontier Labs）展現出前所未有的資本消耗速度。以 Anthropic 為例， SEC 揭露文件與市場數據顯示，其累積的算力承諾（Compute Commitments）總額已高達 $900.9B（約 9,000 億美元）。與此同時，OpenAI 亦推動著龐大的融資計畫與巨額算力需求。這種天文數字級別的固定支出，建構在一個極度緊密的資本生態系之上，將 Google、Amazon、TeraWulf、Broadcom 與 NVIDIA 等硬體、電力及雲端服務提供者深度綁定。

從 Benjamin Graham 與 Warren Buffett 的價值投資架構審視，前沿模型公司當前的商業模式存在結構性的脆弱點。Graham 著重企業的清算價值與安全邊際，而前沿模型公司本身屬於高固定成本、高營運槓桿（Operational Leverage）企業，目前普遍缺乏足以自我維持的自由現金流（Free Cash Flow）。當市場資金充沛、融資順暢時，高額算力承諾可作為擴展規模的燃料；然而，一旦總體經濟環境轉變、科技資本支出週期反轉，或後續融資受阻，龐大的算力租約便會立即轉化為致命的財務負擔。

這類龐大的算力承諾並非僅停留在模型公司的資產負債表內，更會透過合約關係向外擴散，形成複雜的連鎖對手方風險：

1. **電力與資料中心基礎設施商：** 簽署長達數十年、數億甚至百億美元的 HPC（高效能運算）資料中心租約，若模型公司違約，資料中心營運商將面臨巨大的空置與應收帳款風險。
2. **晶片與系統供應商：** 如 Broadcom 與 NVIDIA，其未來幾年的營收預測高度依賴模型公司的資本支出承諾與硬體拉貨。
3. **雲端服務提供者（CSPs）：** 如 Amazon AWS 與 Google Cloud，既是模型公司的股東與融資方，也是其最大的服務供應商與通路。

價值投資人應明確區分「表層股權價值」與「深層合約資產」。前沿模型公司若將大量資本鎖定在不可撤銷的長期算力合約中，一旦營收成長放緩，破產重組的風險將呈指數級上升，進而對整個連鎖生態系產生資產重估的壓力。

## 2. 商業模式與護城河：前沿模型公司 vs. 雲端巨頭的價值捕獲 (Value Capture)

在 AI 產業的架構中，獨立模型公司與雲端巨頭在護城河持久度（Moat Durability）與獲利捕獲能力上存在本質差異。

### 模型層的商品化隱憂與獲利瓶頸
獨立模型公司（如 Anthropic、OpenAI）面臨極高的研發費用、沉重的安全治理成本、頻繁的員工股權稀釋以及極高的營運風險。最為關鍵的是，前沿模型面臨著「模型商品化」（Model Commoditization）的結構性威脅。當市場上多個模型在效能上趨於同質化時，單純的模型 API 訂價權將迅速喪失，邊際利潤隨之下滑。若模型層無法建立起強大的用戶黏性與網路效應，利潤將不可避免地向產業鏈的上游（晶片與基礎設施）及下游（雲端分發與應用端）遷移。

### 雲端巨頭的「賣鏟子 + 挖金子 + 困境收購」三層架構
相比之下，雲端巨頭建構了三重價值的防禦體系：

1. **賣鏟子（Selling Shovels）：** 提供基礎算力與基礎設施，無論哪一家模型公司勝出，皆需支付基礎架構費用（AWS Compute / Azure / Google Cloud）。
2. **客製化晶片與利潤防禦（Custom Silicon & Margin Defense）：** 雲端巨頭自行研發 ASIC 晶片（如 Google 的 TPU、Amazon 的 Trainium），有效降低推論與訓練的單位成本，鎖定高毛利。
3. **雲端分發與生態系困境期權（Cloud Distribution & Distress Optionality）：** 透過企業級客戶關係（如 AWS Bedrock、Microsoft Copilot、Google Cloud），巨頭掌控了最終的市場分發通路。同時，若合作的模型公司陷入困境，巨頭可利用資金與合約優勢，以極低成本進行資產收購或權利接管。

| 公司 / 類別 | 核心 AI 戰略資產 | 算力與晶片依賴 | 困境下的防禦與清算機制 |
| :--- | :--- | :--- | :--- |
| **雲端巨頭**<br>(Google, Amazon, Microsoft) | 雲端基礎設施、企業分發通路、客製晶片 (TPU/Trainium)、自有模型/IP | 低至中（具備自研晶片與多模型相容能力） | 高度防禦。擁有自由現金流保護，具備合約 Backstop、債務重組議價權與資產接管期權。 |
| **前沿模型公司**<br>(Anthropic, OpenAI) | 前沿模型 IP、頂尖研究團隊、品牌認知、專屬軟體 (Claude Code, ChatGPT) | 極高（高度依賴外部 GPU/TPU/Trainium 及巨頭雲端） | 脆弱。缺乏自由現金流，固定算力承諾沉重，若破產股權面臨歸零風險。 |

## 3. 資本配置與戰略期權：Google 與 Amazon 的防禦與上行空間 (Distress Optionality)

針對 Anthropic 的投資與合作，Google 與 Amazon 採取了截然不同的合約設計與資本配置策略，這決定了兩者在 Anthropic 面臨財務困境時的風險承受力與上行期權。

### Google 的破產期權與低風險結構
Google 對 Anthropic 的布局展示了極高明的不對稱風險控管（Asymmetric Risk Protection），形成典型的「贏則大獲全勝，輸亦無實質損害」（Heads I win, tails I don't lose）的戰略期權。

根據 TeraWulf 向 SEC 披露的監管文件顯示，Anthropic 與 TeraWulf 簽署了約 401 MW、20 年期的高效能運算（HPC）資料中心租約，總合同價值約為 $19B。值得注意的是，SEC 揭露文件明確指出，Google 於 2026 年 11 月 4 日為這些 Anthropic 租約提供了信用背書（Credit Backstop）。

根據合約條款規定，若 Anthropic 出現支付違約（Payment Default）甚至陷入無清償能力事件（Insolvency Event），Google 擁有以下明確的選擇權：
1. 替 Anthropic 補齊租金並直接接管該資料中心租約；或
2. 支付終止費以終止租約，並在特定條件下取得資料中心地主子公司（Landlord Subsidiary）的股權（Equity Interest）。

此一結構意味著，Google 無需全盤收購 Anthropic 整家公司及其潛在負債，即可在 Anthropic 違約時直接掌控 401 MW 通電的優質資料中心算力資產。在資本層面，Google 在 Anthropic IPO 後持股約 13.4%（主要為無投票權的 Class N 股份），並於 IPO 同步私募（Concurrent Placement）中追加投資 $10B，此前亦有最高約 $20B 的融資安排。同時，Anthropic 於 4 月與 Google 及 Broadcom 簽訂了自 2027 年上線的多 Gigawatts TPU 產能協議。

Google 的優勢在於：若 Anthropic 成功，Google 賺取 TPU/Cloud 營收與股權增值；若 Anthropic 失敗，Google 不僅能憑藉 Backstop 條款低價接收貴重資料中心算力資產，其自有的 Gemini 模型更能直接吸收 Anthropic 釋出的市場份額。然而，由於 Google 自有 Gemini，全盤併購 Anthropic 將面臨極大的反壟斷（Antitrust）審查壓力（FTC 於 2025 年即對 Hyperscaler 與 AI Lab 的合作展開專案調查）。

### Amazon 的沉沒成本與垂直整合轉機
相較於 Google，Amazon 與 Anthropic 的營運依賴度（Operational Dependency）更深。

公開數據顯示，Anthropic 承諾未來十年在 AWS 技術上支出超過 $100B，鎖定最高約 5 GW 的產能，並已部署使用超過 100 萬顆 Trainium2 晶片；超過 100,000 家企業客戶透過 Amazon Bedrock 採用 Claude，而 Project Rainier 更是 Anthropic 訓練的核心基礎設施之一。Amazon 目前持有 Anthropic 約 14.6% 的 Class N 經濟權益。

若 Anthropic 發生違約，Amazon 短期將面臨顯著衝擊：
* 股權價值減損；
* 未來超 $100B 的 AWS 預期營收面臨風險；
* Trainium 晶片利用率下降；
* Bedrock 平台上的 Claude 客戶需進行遷移。

然而，短期衝擊背後蘊含著巨大的長期轉機。Amazon 當前 AI 戰略最大的缺口在於缺乏具備頂級品牌認知的自研前沿模型（其架構為：Trainium 晶片 → ??? → Bedrock / AWS）。若 Anthropic 進入困境重組，Amazon 能以重置價格（Distressed Valuation）取得 Claude IP、Claude Code、研究團隊與客戶關係，即可完美補齊戰略拼圖，轉化為高度垂直整合的 AI 平台（Trainium → Claude → Bedrock / AWS）。

| 戰略指標 | Google | Amazon |
| :--- | :--- | :--- |
| **自研前沿模型** | 擁有強大的 Gemini | 相對較弱，高度依賴 Anthropic |
| **算力與晶片合作** | TPU + Google Cloud | Trainium + AWS (Project Rainier) |
| **Anthropic 消失的直接影響** | 利好 Gemini，可吸收市場需求與客戶 | 短期受創（失去大客戶與 $100B 預期營收） |
| **收購 Claude 的戰略價值** | 價值高但存在重疊，替代性強 | 極高，能補齊 AI Stack 最關鍵缺口 |
| **反壟斷審查風險** | 極高（Gemini + Claude 合併敏感度極高） | 敏感，但補齊效應邏輯比雙巨頭壟斷更易辯護 |
| **困境保護機制** | 具備 401 MW HPC 租約信用背書 (Backstop) | 巨大的 AWS 業務合約與轉股融資曝光 |

## 4. 破產法規、清算瀑布與合約地圖 (Bankruptcy & Capital Structure Waterfall)

當前沿模型公司面臨資本鏈斷裂時，市場往往誤以為大股東可以直接接管公司。然而，在美國破產法第 11 章（Chapter 11）的法律框架下，資產處置受制於嚴格的資本結構清算瀑布（Liquidation Waterfall）與法庭裁定。

### 清算瀑布（Liquidation Waterfall）與資本優先級
在 Chapter 11 程序中，資產價值的分配嚴格遵循受償順序：

$$\text{有擔保債務人 (Secured Creditors)} \longrightarrow \text{行政破產費用 (Administrative Claims)} \longrightarrow \text{無擔保債務人 (Unsecured Creditors)} \longrightarrow \text{優先股東 (Preferred Equity)} \longrightarrow \text{普通股東 (Common Shareholders)}$$

Anthropic IPO 後，Founder LLC 與 Long-Term Benefit Trust 掌握實質控制權，而 Amazon（持股約 14.6%）與 Google（持股約 13.4%）主要持有無投票權的 Class N 股份。在清算瀑布中，普通股權處於最受償劣後的位置（Junior Status），不提供任何特殊救濟權利。若公司資產價值不足以清償債務，股權價值將直接歸零。

### 合約與債權所帶來的談判籌碼
股權雖然可能歸零，但巨頭們透過 senior 級別的合約與債權架構，在破產法第 363 條（§363 Asset Sale）資產出售或債務重組中建立起真正的談判主導權（Bargaining Power）：

* **Google：** 股權 + 融資 + TPU 供應 + Cloud 租約 + 401 MW HPC 租約背書（Backstop）。
* **Amazon：** 股權 + 可轉換融資 + 超 $100B AWS 服務合約 + 100 萬顆 Trainium2 部署 + Project Rainier。
* **Broadcom：** 融資安排 + TPU 基礎設施供應。
* **NVIDIA：** $10B 股權投資 + GPU 核心供應商（$10B 股權若無債權附帶則面臨較高股權減損風險，但其 GPU 供應不可或缺）。

在 §363 資產出售程序中，擁有高級債權、租約擔保及核心供應合約的夥伴，能以「扣抵下標」（Credit Bidding）或提供 DIP（Debtor-in-Possession）融資的形式，壓制純股權持有人，主導模型 IP 與算力資產的重組方向。

### 前沿模型公司財務困境的三大演變情景

1. **情景 A：資本重組（Recapitalization / 債轉股）：**
   若 Anthropic 的技術與營收成長依然強勁，僅因 $900.9B 的算力承諾負擔過重，最理性的商業結果是債權人與雲端巨頭重新談判合約。透過「債轉股」（Debt for Equity）並調降未來的算力承諾，使公司減輕負債並保持獨立營運。
2. **情景 B：資產拆售（Split Sale）：**
   若獨立公司無法維持，法人結構解體。Claude IP 與 Claude Code 被某家 Hyperscaler 併購；研究團隊流向另一家公司；算力合約與資料中心租約則由 Google、Amazon 或其他 CSP 接管。法人雖然消失，但 Claude 技術資產得以延續。
3. **情景 C：戰略收購（Strategic Takeover）：**
   由 Amazon 或 Google 進行整體併購。此情景雖然在法律上可行，但必定會觸發 FTC 等監管機構嚴苛的反壟斷審查，執法障礙極高。

## 5. OpenAI 資本棋局與 Microsoft / Amazon 的戰略綁定

OpenAI 的資本結構與救援邏輯與 Anthropic 存在異曲同工之處，但 Microsoft 透過早期極具前瞻性的條款，建立了更為深厚的保護傘。

### Microsoft 的核心條款與 IP 保護傘
根據 2026 年雙方公布的最新協議細節，Microsoft 在 OpenAI 生態系中擁有極其特殊的結構性優勢：
* **IP 授權期限：** Microsoft 擁有 OpenAI 模型與產品 IP 的智慧財產權授權，效期長達 **2032 年**。
* **股權結構：** 2025 年重組後，OpenAI Foundation 控制 OpenAI Group 並持股約 26%；Microsoft 持股約 27%；員工及其他投資者持股約 47%。
* **雲端與產品條款：** Azure 依然為 primary cloud partner，且 OpenAI 的新產品原則上享有在 Azure 上優先發布（First Ship）的權利。

因為 OpenAI 具備無可替代的戰略價值與品牌影響力，市場直接對其進行清算拍賣（Chapter 7 Liquidation）的可能性極低。即使 OpenAI 出現嚴重的資金鏈斷裂，Microsoft 的股權價值雖會受損，但其對 OpenAI 核心技術 IP 長達至 2032 年的使用權與 Azure 整合權並不會消失。Microsoft 無需完整收購 OpenAI，即可持續將其技術轉化為 Copilot 等企業級產品營收。

### 2026 年 OpenAI 新生態陣營與救援財團邏輯
至 2026 年，OpenAI 的資本陣營已大幅擴張，不再由 Microsoft 獨占。新一輪融資與戰略合作包括：
* **SoftBank：** 投資 $30B。
* **NVIDIA：** 投資 $30B，並深化算力合作（包含在 Vera Rubin 架構上推動 3GW 推論 + 2GW 訓練，此前已宣布至少 10GW 的戰略合作）。
* **Amazon：** 投資 $50B，AWS 成為 OpenAI Frontier 獨家第三方雲端分發管道，並配合 2GW Trainium 產能構建 Stateful Runtime。

由於直接清算幾乎不可能，一旦 OpenAI 出現高達數百億美元的資金缺口，更可能觸發由 **Microsoft、Amazon、SoftBank、NVIDIA 與 Oracle** 組成的「救援資本財團」（Rescue Capital Consortium）。在救援融資（Rescue Financing）過程中，資本巨頭將透過挹注資金，重新劃分各自最渴望的資產：

```
救援資本財團 (Rescue Capital Consortium)
├── Microsoft ─── 換取更長 IP 授權 / 更高 Azure 綁定 / 產品優先權
├── Amazon ────── 換取 Trainium 深度整合 / AWS 獨家分發權
├── NVIDIA ────── 確保 GPU / Vera Rubin 訂單與算力需求
├── SoftBank ──── 換取 Stargate 基礎設施股權
```

## 什麼情況會改變我們的看法

作為長期價值投資人，我們保持動態審視的態度。若發生以下 4 個客觀情境，將促使我們修正對 Hyperscalers 隱性期權與價值捕獲的分析結論：

1. **反壟斷監管審查（FTC 等）的實質執法轉變：** 若監管機構實施極端強制措施，全面禁止雲端巨頭對前沿模型公司進行任何資產收購、DIP 融資或破產接管，將切斷巨頭利用困境期權獲取 IP 的路徑。
2. **自研晶片（ASIC/TPU/Trainium）對 GPU 的大規模替代速度：** 若客製化晶片在訓練與推論的效能費用比徹底擊敗通用 GPU，將顯著重塑 NVIDIA 的高毛利結構與雲端巨頭的算力資本支出負擔。
3. **前沿模型出現真正的突破性獨占護城河：** 若某一模型公司實現自我維持的超高自由現金流（例如突破性的 Killer App 帶來強大定價權與高留存率），完全擺脫對 Hyperscalers 的資本依賴，模型層的價值將被重新定價。
4. **合約條款與清算瀑布的重大法律變更：** 若破產法庭裁定雲端託管合約或 Backstop 信用背書協議無效或不予執行，將削弱 Google 或 Amazon 在困境重組中的保護性資產接管能力。

## 長期投資人的實用重點

綜合上述分析，價值投資人應從 AI 產業的資本演化中汲取以下核心啟示：

* **資本分配的黃金法則：警惕高營運槓桿的模型 Lab：** 避免過度追捧缺乏自由現金流、卻承擔巨額固定算力承諾的模型公司。在資本反轉週期中，高固定成本企業的普通股權往往承受最大的清算風險。
* **重視「賣鏟子 + 資本期權」的結構優勢：** 雲端巨頭（Google、Amazon、Microsoft）具備高度不對稱的勝率（Asymmetric Risk/Reward）：
  * **模型公司成功：** 巨頭分享雲端算力營收、晶片分發與股權增值；
  * **模型商品化：** 巨頭憑藉企業通路、應用整合與晶片優勢捕獲最終利潤；
  * **模型公司失敗：** 巨頭利用合約 Backstop 與強大資產負債表，以低價重估值接管 IP、團隊與資料中心算力。
* **聚焦資本瀑布中的權利地圖，非僅看股權比例：** 投資人在評估 AI 產業鏈風險時，不能僅關注表面的股權持有率，更須繪製包含債權、guarantees、HPC Backstop 及雲端綁定合約的「資本與合約地圖」（Capital + Contract Map），這才是決定破產重組時真正權力歸屬的核心依據。
